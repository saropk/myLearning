# design/

`reference.png` goes here: the user-provided black-hole reference image that ATHENA.md
names as the **acceptance standard** for the Aegis emblem.

It is not in the repository yet, and it is needed before phase 6 starts. Per the spec, no
emblem milestone is "done" until the user approves it side-by-side against this image on
screen — so nothing about the emblem should be built from memory or from a description.
